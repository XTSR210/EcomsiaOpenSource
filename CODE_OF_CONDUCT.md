# Code de conduite — Ecomsia Open Source

## Notre engagement

Nous nous engageons à faire de ce projet une expérience exempte de harcèlement pour tout le monde, quelle que soit l'identité ou l'expression de genre, l'orientation sexuelle, le handicap, l'apparence physique, la taille, l'origine ethnique, la nationalité, l'âge, la religion ou le choix technologique.

## Nos standards

**Comportements positifs :**
- Faire preuve d'empathie et de bienveillance envers les autres
- Respecter les opinions et expériences différentes
- Donner et accepter gracieusement les retours constructifs
- Assumer ses erreurs et s'excuser auprès des personnes concernées

**Comportements inacceptables :**
- Langage ou imagerie sexualisés, harcèlement sous toute forme
- Trolls, insultes, attaques personnelles ou politiques
- Publication d'informations privées sans consentement
- Tout autre comportement déraisonnable dans un cadre professionnel

## Application

Les manquements peuvent être signalés aux mainteneurs via GitHub (contact du propriétaire du dépôt). Toute décision de modération est prise avec équité et peut être expliquée sur demande.

Cette charte est adaptée du [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
