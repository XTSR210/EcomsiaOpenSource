# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans ce dépôt, **n'ouvrez pas d'issue publique**.

Utilisez plutôt les [rapports de vulnérabilité privés GitHub](https://github.com/XTSR210/EcomsiaOpenSource/security/advisories/new) (onglet *Security* → *Report a vulnerability*), ou contactez le propriétaire du dépôt directement.

## Ce qui entre dans le périmètre

- Les sources de ce dépôt (`src/`, `ui/`, scripts, CI)
- Les exemples et la documentation

## Ce qui n'entre pas dans le périmètre

- La plateforme Ecomsia elle-même (site, API, comptes utilisateurs) — le SaaS reste privé et ses failles éventuelles doivent être signalées via ecomsia.fr
- Les dépendances tierces : remontez-les à leurs mainteneurs respectifs

## Délai de réponse

Les signalements sont traités sous 7 jours ouvrés, avec publication d'un correctif ou d'un avis selon la gravité.
